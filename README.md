# FZXF-data · 关卡数据库

《重生之我是反诈先锋》的关卡数据源，供线上网页 `xiguahahaha/FZXF` 运行时拉取。

**数据地址**：https://xiguahahaha.github.io/FZXF-data/levels.js

## 用法

改完 `levels.js` 后直接 push 即可，网页仓库**不用重新部署**：

```bash
git add levels.js && git commit -m "加关/改话术" && git push
```

生效时间约 1～3 分钟（GitHub Pages 缓存）。网页端每次打开都会重新拉取，并校验 `mid / youth / elder` 三个数组都存在才覆盖；拉不到就自动回落网页仓库内的本地副本，不影响游玩。

## 当前关卡

| 身份线 | 关卡数 | 说明 |
|---|---|---|
| `mid` 中年 | 20 | 冒充客服、刷单、杀猪盘、公检法、荐股等 |
| `youth` 青年 | 15 | 游戏账号担保、裸聊敲诈、注销校园贷、跑分洗钱等 |
| `elder` 老年 | 15 | 冒充孙子、养老金认证、民族资产解冻、上门安装等 |

合计 50 关，每局随机抽 5 关（中老年两池互掺 1 关）。

## 加关格式

往对应身份线的数组里追加对象即可，字段结构见 `levels.js` 顶部注释，游戏会自动纳入随机池。
